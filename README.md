# odin-recipes

#¿Qué es esto?
Este es el primer proyecto para practicar los conocimientos aprendidos en The Odin Project.
Consiste en la creacion de un sitio web de recetas usando solo HTML.
Este proyecto viene en FUNDATIONS, seccion HTML FUNDATIONS.

#¿Qué conocimientos son los que se practicaran?
Los conocimientos y habilidades a manejar son
    -Etiquetas de html
    -Imagens y links de html
    -Listas ordenadas y no ordenadas de html
    -La elaboración de buenos commits
